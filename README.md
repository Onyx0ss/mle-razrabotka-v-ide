# mle-razrabotka-v-ide

Шаблон репозитория для самостоятельного задания спринта 6 курса Инженер Машинного Обучения Яндекс Практикума

Этот проект предназначен для автоматического создания отчетов на основе необработанных данных.

# Установка необходимых библиотек:

Для установки необходимых библиотек выполните команду в терминале, предварительно активировав виртуальное окружение Python:

pip install -r requirements.txt

# Запуск:

Для создания отчета выполните команду в терминале, находясь в корневой папке проекта:

python3 main.py
